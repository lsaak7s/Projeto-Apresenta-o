# 🍔 Apresentação

⚙️ Este projeto foi desenvolvido durante meus estudos de **JavaScript**, com foco em lógica de programação, manipulação do DOM e métodos de arrays.

Um cardápio interativo onde é possível visualizar os produtos, filtrar opções veganas, calcular o valor total e aplicar desconto para pagamento via Pix.

**HTML • CSS • JavaScript**

---

## 📌 Sobre o projeto

O **Dev Burguer** é uma aplicação web desenvolvida com **HTML5, CSS3 e JavaScript**, criada para colocar em prática conceitos importantes de JavaScript através de uma aplicação funcional.

O projeto trabalha com produtos armazenados em arrays e utiliza métodos como `map()`, `filter()` e `reduce()` para manipular os dados e atualizar as informações exibidas na tela.

---

## ✨ Funcionalidades

* 🍔 Exibição dos produtos
* 🌱 Filtro de produtos veganos
* 💰 Cálculo do valor total
* 💸 Desconto de 20% para pagamento via Pix
* 🔄 Atualização dinâmica dos produtos
* ⚡ Interação através de botões
* 💵 Formatação dos valores

## 🧠 Métodos de Array utilizados

### `map()`

Utilizado para percorrer os produtos e criar os elementos exibidos na página.

### `filter()`

Utilizado para filtrar os produtos, como na opção de visualizar apenas os produtos veganos.

### `reduce()`

Utilizado para somar os valores dos produtos e calcular o total da compra.
